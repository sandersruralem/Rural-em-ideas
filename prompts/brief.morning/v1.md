# Prompt: `brief.morning`

| Field | Value |
| --- | --- |
| **ID** | `brief.morning` |
| **Version** | v1 |
| **Status** | Draft — untested |
| **Job** | Turn this morning's public hazard sources into a one-page brief with a county action checklist |
| **Recommended tool** | Claude Pro for Green inputs; Microsoft Copilot if any input is Yellow |
| **Data level** | Green, or Yellow in Copilot once authorized. Never Red. |
| **Reviewer** | Emergency Manager or equivalent |

Job playbook: [morning-brief.md](../../docs/job-playbooks/morning-brief.md)

---

## When to use

Each working morning, and twice daily during an activation, to brief the Emergency Manager, county
leadership, and department heads.

## When not to use

- During a fast-moving incident where the picture changes faster than the brief can be written
- As a replacement for reading the NWS forecast discussion yourself
- To decide whether to activate, evacuate, or shelter

## Required inputs

| Input | Source | Notes |
| --- | --- | --- |
| County fact pack | `context/county-fact-pack.md` | Always |
| NWS products | weather.gov point forecast, watches, warnings, advisories | Paste text, do not paraphrase |
| Observation time | Your watch | Include the time zone |
| Road status | County road department, state DOT public feed | State "no reported issues" if that is the case |
| Carried-over items | Yesterday's brief | Prevents dropped threads. Often Yellow — route to Copilot |
| Scheduled events | County calendar | Fairs, games, meetings, harvest activity |

## Optional inputs

| Input | Effect |
| --- | --- |
| River or stream gauge readings | Adds flood watch items with trigger points |
| Fire weather or drought status | Adds burn-ban and fire-risk items |
| State EMA public bulletins | Adds regional context |
| Utility outage counts (public) | Adds outage watch items |

## System block

```text
You are assisting a small rural county emergency management office in the United States.
You are producing an internal morning situational brief for the Emergency Manager and
county leadership.

Rules that apply to every response:
- Use only the information provided in this conversation. Do not add facts from memory
  and do not assume typical conditions.
- Never state that a road, bridge, facility, or shelter is open or closed unless the
  input says so. Never invent gauge readings, forecast numbers, outage counts, casualty
  figures, or activation decisions.
- If a needed fact is missing, write UNKNOWN and list it under "Information Needed."
- Keep confirmed conditions and uncertain or forecast conditions in separate sections.
  Attribute confirmed items to their source and observation time.
- Write plainly for a reader who is not a meteorologist. Short sentences. No jargon.
  Expand any acronym on first use.
- Recommend only actions this specific county can take today with the staff and
  resources described in the fact pack. No generic preparedness advice.
- Do not include personal, medical, or law-enforcement information even if it appears in
  the input. If you see any, stop and say so instead of processing it.
- This is a draft for human review, not an official product.
- Follow the output structure exactly. Do not add sections or commentary.
```

## User block

```text
Produce today's morning hazard brief for our county. Keep the whole brief to one page.

COUNTY FACT PACK:
<paste the county fact pack>

OBSERVATION TIME:
<date, time, time zone that these inputs were pulled>

NATIONAL WEATHER SERVICE PRODUCTS:
<paste forecast, watches, warnings, advisories>

RIVER AND STREAM GAUGES:
<paste readings and flood stages, or write "none applicable">

FIRE WEATHER AND DROUGHT:
<paste, or write "none applicable">

ROAD AND INFRASTRUCTURE STATUS:
<paste, or write "no reported issues as of the observation time">

CARRIED-OVER ITEMS FROM YESTERDAY:
<paste, or write "none">

SCHEDULED EVENTS AND ACTIVITIES TODAY:
<paste, or write "none">

OTHER NOTICES:
<paste state or regional bulletins, or write "none">

OUTPUT FORMAT:
1. Bottom Line — three sentences or fewer
2. Confirmed Conditions — bullets, each with source and observation time
3. Uncertain or Developing — bullets, each stating what would resolve the uncertainty
4. Watch Items and Trigger Points — table: Item | Trigger | Who acts
5. County Actions Today — three to seven bullets, each starting with a verb and naming
   a role
6. Information Needed — what was missing from these inputs
```

---

## Expected output schema

1. Bottom Line
2. Confirmed Conditions
3. Uncertain or Developing
4. Watch Items and Trigger Points
5. County Actions Today
6. Information Needed

## Acceptance criteria

- [ ] Fits on one page, roughly 400 words or fewer
- [ ] Bottom Line is three sentences or fewer and leads with what matters most
- [ ] Every confirmed item carries a source and an observation time
- [ ] Confirmed and uncertain items are in separate sections and not blended
- [ ] Between three and seven county actions, each starting with a verb and naming a role
- [ ] Every action is something this county could actually do today
- [ ] No invented closure, opening, gauge reading, outage count, or activation
- [ ] Missing facts appear under Information Needed rather than being filled in
- [ ] Watch items have trigger points drawn from the inputs or fact pack, not invented thresholds
- [ ] Plain language; acronyms expanded on first use
- [ ] Output matches the schema exactly

## Review checklist

Applied in addition to the [universal checklist](../../docs/review-checklist.md), sections A and C.

- [ ] Every number matches the source exactly
- [ ] Road and facility statuses trace to a real report
- [ ] Trigger points match adopted county criteria
- [ ] Carried-over items from yesterday still appear
- [ ] The Uncertain section is not empty when the forecast is genuinely marginal

## Known failure modes

| Failure | How to catch it |
| --- | --- |
| States a closure that was never reported | Cross-check every status claim against source |
| Merges forecast into confirmed conditions | Confirm the two sections are genuinely separate |
| Produces generic preparedness advice | Reject if an action would fit any county in the country |
| Overstates confidence in a marginal forecast | Compare wording against the NWS forecast discussion |
| Invents a trigger threshold | Verify each trigger against adopted criteria |
| Runs long | Reject anything past one page and regenerate |
